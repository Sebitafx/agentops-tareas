Solicitar eliminación de datos

  1. Escribe a oriundotafur@gmail.com con el asunto «Eliminar mis datos de AgentOps Tareas».
  2. Indica el número de WhatsApp que usaste, con código de país. Envía esa información únicamente al correo de contacto, sin publicarla en GitHub ni en foros.
  3. La administración verificará que la solicitud corresponde al titular del número mediante una confirmación con el participante, antes de eliminar registros.
  4. Una vez comprobada la solicitud, la administración eliminará de la base del proyecto los mensajes asociados al número y los estados de entrega que pueda vincular a esos mensajes, y te comunicará el resultado por correo.

Puedes solicitar también que tu número deje de estar autorizado para enviar mensajes a la demostración. No envíes contraseñas, códigos de verificación ni documentos de identidad.

Esta página contiene instrucciones: abrirla no elimina datos automáticamente. El proyecto no puede borrar las copias que los proveedores conserven de manera independiente.
